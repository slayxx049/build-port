# Build/Log — Personal Portfolio

A responsive single-page portfolio featuring:
- Dark, editorial-style introduction and project archive
- Animated digital globe in the projects section
- Interactive 3D keyboard: each key represents one of the listed programming languages or developer tools
- Reversible scroll reveals and a scroll-progress timeline
- Cosmic particle field integrated into the build-history background
- Translucent, gooey, velocity-responsive custom pointer on desktop; the system pointer is hidden while the site is active
- Smooth anchor scrolling and responsive layouts

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with the email address you want displayed.
2. Review project descriptions and statuses for accuracy.
3. Add verified dates to the timeline if you want calendar dates shown.
4. Add screenshots or links to project demonstrations where appropriate.

## Hosting
This repository is public. Do not add API keys, passwords, private project source code, or personal data. GitHub Pages can host the public portfolio from this repository.
