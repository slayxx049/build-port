# Build/Log — Personal Portfolio

A responsive single-page portfolio featuring:
- Cybersecurity-inspired introduction
- Project showcase with animated digital globe
- Pricedown-inspired technical skills typography
- Coding and building history timeline
- Interactive cosmic particle section
- Translucent, velocity-responsive jelly cursor on desktop
- Smooth scrolling and reveal transitions

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with the email address you want displayed.
2. Review project descriptions and statuses for accuracy.
3. Add exact dates to the timeline if you want calendar dates shown.
4. Add screenshots or links to project demonstrations where appropriate.

## Font note
The visual uses **Black Ops One** as a readily available display-font fallback. It is not the proprietary Pricedown font shown in the reference. If you have a properly licensed Pricedown font file, place it in `assets/fonts/` and define it with `@font-face` in `style.css`.

## Hosting
This repository is currently public. Do not add API keys, passwords, private project source code, or personal data. GitHub Pages can host the public portfolio from this repository.
